{{/* tk/get-logo - the site logo as an $img dict .page — Page — page context for tk/get-asset (optional) .process — string — Hugo process string for a raster logo, e.g. "resize x90". A bare size such as "x90" or "200x" gets "resize " prepended (optional, default unprocessed) .noPublish — bool — passed to tk/get-asset: a raster logo's original is not published and "src" is empty; use .res yourself (optional, default false) site.Params.ui.logo — string — logo path (optional). Unset, the first of assets/brand/logo.svg, assets/brand/logo.png that exists; neither, "brand/logo.svg" via the static fallback The logo is assumed to be in assets/, which makes it a resource that can be resized and packed into favicons. A static/ logo still resolves, through tk/get-asset's static fallback, but cannot be processed; nor can an SVG. returns ($img dict — see tk/get-asset-help.html for the fields) DO NOT call partial "tk/dbg-template" - it prevents return from working. */}} {{- $process := .process | default "" -}} {{- if and $process (not (in (slice "resize" "fit" "fill" "crop" "process") (index (split $process " ") 0))) -}} {{- $process = printf "resize %s" $process -}} {{- end -}} {{- $logo := site.Params.ui.logo -}} {{- if not $logo -}} {{- $logo = "brand/logo.svg" -}} {{- if and (not (resources.Get $logo)) (resources.Get "brand/logo.png") -}} {{- $logo = "brand/logo.png" -}} {{- end -}} {{- end -}} {{- $ret := partial "tk/get-asset" (dict "page" .page "asset" $logo "process" $process "noPublish" .noPublish) -}} {{- return $ret -}}
