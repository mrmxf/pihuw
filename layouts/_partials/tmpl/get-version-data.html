{{- /* tmpl/get-version-data Returns a dict of the first entry in the releases YAML file. Reads: site.Params.releaseTracking — path to the releases YAML, relative to the Hugo data directory (default "data/releases.yaml") Since v0.4.10 the file lives in data/, not assets/data/, so it is read through hugo.Data rather than resources.Get. The param is still written as a path; the leading "data/" and the extension are stripped to give the hugo.Data key, so a consumer's existing `releaseTracking: data/releases.yaml` keeps working. returns (dict) — first entry from the YAML list, or "" if the file is missing/empty DO NOT call partial "tk/dbg-template" - it prevents return from working. */ -}} {{- $ret := "" -}} {{- $file := site.Params.releaseTracking | default "data/releases.yaml" -}} {{- $key := strings.TrimSuffix (path.Ext $file) (strings.TrimPrefix "data/" $file) -}} {{- $node := hugo.Data -}} {{- range split $key "/" -}} {{- $node = index ($node | default dict) . -}} {{- end -}} {{- with $node -}} {{- $ret = index . 0 -}} {{- end -}} {{- return $ret -}}
