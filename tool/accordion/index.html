Usage
{{< accordion inner = "acc-tab content" >}}
Use with acc-tab partials to create collapsible content sections
Description

Creates an interactive accordion container with collapsible sections. Perfect for organizing content into expandable/collapsible tabs that help manage page space and improve user experience.

Must contain acc-tab partials as child content
Uses CSS transitions for smooth animations
Supports multiple open tabs simultaneously
Includes hover animations for better user interaction
Parameters

indicates required parameter

inner = "string"REQUIRED
Contains acc-tab partials that define the accordion sections

Additional Information
Interactive design: Users can expand/collapse sections independently
Smooth animations: CSS transitions provide polished user experience
Accessible markup: Proper checkbox/label structure for screen readers
Flexible content: Supports markdown, shortcodes, and nested partials
Common vocabulary: Use hw shortcode parameters for consistent styling
Must contain acc-tab partials - empty accordions will not display properly
Performance consideration: Many open sections with complex content may impact page speed
Mobile responsive: Test accordion behavior on smaller screens
