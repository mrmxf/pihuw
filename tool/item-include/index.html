Includes another page as an item in a list with automatic metadata extraction
Description

Includes another page’s content as a formatted item, automatically extracting the page’s title, featured image, description, and metadata. Perfect for creating content lists and navigation aids with consistent item formatting.

Automatic metadata extraction from target page’s frontmatter
Content processing removes frontmatter and processes markdown/HTML
Featured image discovery with fallback options from page parameters
Reading time calculation based on word count (220 words/minute)
Parameters

indicates required parameter

from = "string"REQUIRED
Path to the file to include (relative to project root)
src = "string"
Override image source (takes precedence over automatic detection)
text = "string"
Override description text (takes precedence over page content)

Additional Information
Smart content extraction: Automatically removes frontmatter and processes markdown/HTML
Metadata priority: Uses page parameters, then automatic discovery for images and content
Content fallback: Uses IncludeSummary parameter if available, otherwise processes full content
Image discovery: Checks src parameter, img parameter, then featured images
Reading time calculation: Provides estimated reading time based on content length
Link generation: Creates proper links to the source page
File existence: Target file must exist or will show error message
Path accuracy: Uses exact file paths - ensure correct relative paths
Performance impact: Multiple includes may slow page generation
