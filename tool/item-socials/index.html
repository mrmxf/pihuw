item-socials

2026-04-02

~3 m
{{< hw t="item-socials" >}}
Usage
{{< item-socials [from = "instagram-mrmxf github-mrmxf"] [skip = "1"] [count = "3"] >}}
A row of social links as Font Awesome 6 brand icons, driven by site.Params.social
Description

Renders a row of social icons. With no parameters it shows every platform that has a handle in site.Params.social, in a fixed order. The from parameter picks specific platforms, and can override a handle inline for a one-off link. Handles are turned into URLs by a built-in pattern per platform; a value that starts with http is used verbatim, which is the escape hatch for anything the patterns get wrong.

Configure once in site.Params.social, e.g. social: {instagram: mrmxf}
Supported: twitter, facebook, instagram, linkedin, youtube, mastodon, bluesky, tiktok, github, email
Email renders as mailto: and correctly omits target="_blank"
External links get target="_blank" and rel="noopener"
Accessible: each link carries an aria-label; the icon itself is aria-hidden
Parameters

indicates required parameter

from = "string"every platform in site.Params.social that has a value
Space-separated platform tokens. A token is a platform name (instagram) or platform-handle (instagram-mrmxf), where the handle overrides site params for that one link. A handle may itself contain hyphens.
skip = "int"0
Skip this many links from the start of the resolved list.
count = "int"no cap
Cap the row at this many links. Must be 2 or more: the hw shortcode defaults count to 1 for every tool, so 1 cannot be distinguished from not supplying it and is treated as no cap.
page = "object"REQUIREDcurrent page
Hugo page context (automatically provided by the hw shortcode)
Examples
Every configured platform
{{<hw t="item-socials">}}
Reads site.Params.social and renders each platform that has a handle
Specific platforms, handles from site params
{{<hw t="item-socials" from="instagram linkedin github">}}
A token with no handle falls back to site.Params.social
Override a handle inline
{{<hw t="item-socials" from="instagram-mrmxf linkedin-bruce-devlin">}}
Everything after the FIRST hyphen is the handle, so bruce-devlin works
A full URL when the pattern is wrong
{{<hw t="item-socials" from="linkedin-https://www.linkedin.com/company/mrmxf">}}
LinkedIn company pages do not fit the /in/ pattern, so pass the URL
Skip and cap
{{<hw t="item-socials" skip="1" count="3">}}
Drops the first link, then keeps at most three
Additional Information
One style block per page, guarded by a page Store flag
Default order is twitter, facebook, instagram, linkedin, youtube, mastodon, bluesky, tiktok, github, email
Nothing renders when no platform resolves to a handle — no empty container
count="1" does not work: the hw shortcode already defaults count to 1, so the partial cannot tell that apart from no value. Use from with a single token instead
Icons need Font Awesome 6, which the theme ships; brand glyphs move between FA releases
Handles are not validated: a wrong handle produces a link to a missing profile
