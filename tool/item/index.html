Creates list-style content items with optional media and flexible positioning
Description

Creates individual content items designed for list layouts. Similar to blocks but uses Fomantic UI item styling for cleaner list presentations. Perfect for content lists, search results, or article previews.

Uses Fomantic UI item styling for consistent list appearance
Media positioning (left/right) with automatic layout adjustment
Markdown processing for rich content in descriptions
Flexible metadata display with customizable styling
Parameters

indicates required parameter

header = "string"
Item title/header text
description = "string"
Main item content (processed with markdownify)
inner = "string"
Additional content appended after description (processed with markdownify)
src = "string"
Path to image or media file
srcOn = "string"left
Position of media: ’left’ or ‘right’
Possible values: left or right
meta = "string"
Metadata or additional information displayed below header
headerLink = "string"
URL to make the header clickable
srcLink = "string"
URL to wrap around the media element
srcClass = "string"ui medium image
CSS classes for the media element
alt = "string"summary image
Alt text for media accessibility
id = "string"
HTML ID for the item
